### 🔬 Research Software Portfolio

#### 1. Hysteresis Modelling & Identification

Mathematical modelling and parameter identification for hysteretic materials and smart actuators:

| Repository | Description | Technologies |
|---|---|---|
| [**matlab-preisach-model**](https://github.com/mavasbel-research/matlab-preisach-model) | Discrete and continuous Preisach operator formulations, numerical density function identification, and simulation routines. | MATLAB |
| [**matlab_duhem_model**](https://github.com/mavasbel-research/matlab_duhem_model) | Semilinear Duhem differential model implementation, slope functions, and parameter identification for rate-independent hysteresis. | MATLAB |
| [**tensorflow_hysteresis_models**](https://github.com/mavasbel-research/tensorflow_hysteresis_models) | Deep neural network architectures and custom loss functions for multi-branch hysteresis approximation and remnant state prediction. | Python, TensorFlow |

#### 2. Adaptive Optics & Precision Actuation

Hardware interfaces, calibration routines, and real-time feedback algorithms:

| Repository | Description | Technologies |
|---|---|---|
| [**deformable_mirror**](https://github.com/mavasbel-research/deformable_mirror) | Closed-loop shape control and voltage-to-displacement compensation algorithms for multi-actuator membrane deformable mirrors. | MATLAB, Simulink, C |
| [**piezo_setup**](https://github.com/mavasbel-research/piezo_setup) | Experimental testbed integration, DAQ acquisition routines, and real-time control scripts for piezoelectric positioning stages. | MATLAB, Instrument Control |
| [**shack-hartmaan_sensor_integration**](https://github.com/mavasbel-research/shack-hartmaan_sensor_integration) | Wavefront slope extraction, spot centroiding algorithms, and Zernike modal reconstruction routines for Shack–Hartmann wavefront sensors. | MATLAB, Image Processing |

#### 3. Nonlinear Control & Dynamical Systems

| Repository | Description | Technologies |
|---|---|---|
| [**model_reduction**](https://github.com/mavasbel-research/model_reduction) | Balanced truncation and structure-preserving model order reduction algorithms for high-dimensional mechanical and structural models. | MATLAB |
| [**openai-reinforcement-learning**](https://github.com/mavasbel-research/openai-reinforcement-learning) | Reinforcement learning algorithms and baseline evaluation environments for continuous-space control benchmarks. | Python, OpenAI Gym, PyTorch |
