# Marco Vásquez Beltrán Research

Open research software and reproducible computational work on hysteresis, control, machine learning, and experimental systems.

PhD thesis: [*Multi-loop Hysteresis and Recursive Remnant Control*](https://doi.org/10.33612/diss.215199709), University of Groningen, 2022.
